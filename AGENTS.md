## Project boundaries

- Own exactly 37 IDs: 16 Poké Wool CTM blocks, 16 matching carpet CTM blocks,
  and the five named lower-half static statues. Upper statue halves and all
  other furniture remain stock.
- Compile the exact installed BBS 0.7.2 statue resources at reload into a
  process-local cache. Reject animations, schema drift, missing parents,
  cycles, non-finite values, count drift, texture drift, and resource drift.
- Emit both triangle windings for statue faces. Preserve exact CTM state
  neighbors, carpet height, UVs, facing, and atomic stock fallback.
- BlueMap supplies final lighting; do not claim pixel identity with the
  client's `entityCutoutNoCull` lighting.
- The production and sources JARs must contain no third-party classes, JARs,
  models, textures, BBS files, captures, or derived meshes.
- The add-on activation/profile/adapter framework and Athena CTM implementation
  adapted from the first-party MIT Chipped add-on are permitted and recorded.
  Independently authored scope is limited to CobbleFurnies-specific
  profile/data/orchestration, the bounded BBS/statue path, fixture, and tests.
  Do not copy CobbleFurnies/Athena upstream source or assert an exact source
  commit correlation without new evidence.
- Keep `addon_version=0.1.0-alpha.1` until an approved version task changes it.

## Validation

Use Gradle 9.6.1. Release gates require both artifact properties and must fail
closed if either is absent:

```bash
python3 gallery/generate.py --check
(cd gallery && sha256sum --check SHA256SUMS)
python3 -m unittest discover -s tools/tests -p 'test_*.py'
gradle --no-daemon \
  -PreleaseGate=true \
  -PcobblefurniesJar=/absolute/path/CobbleFurnies-neoforge-1.2.jar \
  -PathenaJar=/absolute/path/athena-neoforge-1.21.1-4.0.6.jar \
  clean check build generatePomFileForAddonPublication \
  generateMetadataFileForAddonPublication verifyPinnedArtifacts
actionlint .github/workflows/*.yml
```

The locked staging fixture is 46 logical cells / 71 physical blocks with the
camera and coordinates generated by `gallery/generate.py`. Before presenting a
BlueMap link, open the exact view and perform the required lightweight visual
sanity check.

Do not stage, commit, tag, publish, push, deploy, or touch remotes unless the
user explicitly authorizes that operation.
