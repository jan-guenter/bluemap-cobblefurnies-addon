# Contributing

Open an issue before expanding the supported byte tuple, loader families, or
visual scope. Compatibility is an exact profile, never a version range.

Contributions must be authored or validly reused under MIT. The existing
add-on activation/profile/adapter framework and Athena CTM implementation come
from the owner's first-party MIT BlueMap Chipped Add-on and must retain their
notice. Do not copy CobbleFurnies or Athena upstream
source, classes, models, textures, translations, captures, or meshes.
Third-party inputs stay local and ignored.

Malformed state and changed schemas must return the whole block to BlueMap's
original path. Submit one coherent change and rely on pull-request CI for the
authoritative clean gate described in [AGENTS.md](AGENTS.md).
